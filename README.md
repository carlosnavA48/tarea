# API NodeJS CRUD

Proyecto básico usando Node.js y Express.

## Tecnologías
- Node.js
- Express
- Git

## Instalación

```bash
npm install
```

## Ejecutar servidor

```bash
node server.js
```

## Endpoints

### Obtener usuarios
GET /users

### Crear usuario
POST /users

### Actualizar usuario
PUT /users/:id

### Eliminar usuario
DELETE /users/:id
